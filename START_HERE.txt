ONLINE VISITOR MANAGEMENT SYSTEM — START HERE
==============================================

1) Extract this ZIP.
2) Install PostgreSQL for Windows (keep pgAdmin 4 selected).
3) In pgAdmin create:
   - Login/Group Role: visitor_app (Can login = Yes; choose a password)
   - Database: visitor_management (Owner = visitor_app)
4) In VS Code open the extracted visitor_management_system folder.
5) Copy backend/.env.example to backend/.env.
6) Edit backend/.env:
   DATABASE_URL=postgresql+psycopg://visitor_app:YOUR_PASSWORD@localhost:5432/visitor_management
   Replace YOUR_PASSWORD with the password you chose.
   Change SECRET_KEY to a long random value. Never upload .env to GitHub.
7) Backend terminal (VS Code -> Terminal -> New Terminal):
   cd backend
   python -m venv .venv
   .venv\Scripts\Activate.ps1
   python -m pip install -r requirements.txt
   uvicorn app.main:app --reload
   If PowerShell blocks activation, use Command Prompt and run:
   .venv\Scripts\activate.bat
8) Check http://127.0.0.1:8000/docs
9) In pgAdmin refresh:
   Databases -> visitor_management -> Schemas -> public -> Tables
   The app creates users and visitor_bookings tables automatically.
10) Open a SECOND VS Code terminal:
    cd frontend
    npm install
    npm run dev
    Open the URL printed, normally http://localhost:5173
11) Import postman/Visitor-Management-System.postman_collection.json.
    Follow postman/TESTING_GUIDE.md. First run GET Health, then POST Seed Demo.
12) Demo accounts (local testing only):
    Employee: employee@example.com / employee123
    Security Head: security@example.com / security123

GitHub:
